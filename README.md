# حاسبة المعدل النقطي الشامل (نظام 4.00) 🎓

تطبيق ويب بسيط وتفاعلي لحساب **المعدل النقطي الشامل (GPA)** للطلاب وفق نظام الساعات المعتمدة (من 4.00) المعتمد في الجامعات السورية الخاصة.

---

## ✨ المميزات

- **إدخال شامل لكل المقررات:** يدخل الطالب اسم المقرر، عدد الساعات المعتمدة (`3` أو `2` أو غيرها)، والدرجة الصحيحة من `100` (بدون كسور أو أنصاص).
- **تحويل فوري ودقيق:** عرض **المكافئ النقطي** (من `0.00` إلى `4.00`) و**التقدير الحرفي** (`A+`, `A`, `A-`, ..., `F`) بجانب كل مقرر فور كتابة الدرجة.
- **حساب تلقائي للمعدل الشامل:** عرض المعدل النقطي النهائي، عدد المقررات، مجموع الساعات، مجموع النقاط، والتقدير العام.
- **مثال تجريبي جاهز:** زر لتعبئة مقررات تجريبية واختبار التطبيق فوراً.
- **واجهة عربية متجاوبة (RTL):** تعمل على الحاسوب والهاتف دون أي مكتبات خارجية.
